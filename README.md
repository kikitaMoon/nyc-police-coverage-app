# NYC Police Response Coverage Analysis

This directory is a deployable ArcGIS Nova app bundle.

Upload the entire directory to your web server. The entry file is `index.html`; do not upload only the entry file.

This bundle uses ArcGIS browser OAuth. The OAuth redirect URL is https://kikitamoon.github.io/nyc-police-coverage-app/.

ArcGIS Nova adds no ArcGIS token, authorization header or client secret to the generated text files. User-provided images are copied as binary content; review them before publishing. If the app is edited in ArcGIS Nova after this bundle is created, run Deploy app again to create a fresh deployable snapshot.
